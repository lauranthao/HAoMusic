网易云音乐 QQ 音乐 酷狗音乐 酷我音乐

多平台合一

四个曲库，一个应用。

网易云音乐、QQ 音乐、酷狗音乐、酷我音乐，在同一个应用里搜索、收藏和播放。扫码登录，可保存多个账号，在设置中随时切换。

网

网易云音乐

每日推荐、精选歌单、排行榜，扫码登录后同步你的歌单与收藏。

Q

QQ 音乐

QQ 音乐曲库与收藏同步，扫码登录，高音质按账号给。

酷

酷狗音乐

酷狗曲库搜索与播放，灰歌自动匹配可播音源。

酷

酷我音乐

酷我曲库搜索与播放，与其他曲库在同一个界面里听。

各平台可用功能不同，以应用内为准。

沉浸歌词

歌词，跟音乐一起走。

点一下封面，歌词就出现在封面位置；点歌词行，直接跳到那一句。逐行同步，跟着播放进度走。

  • 逐行同步
  • 点封面切换歌词
  • 点歌词行跳转
  • 跟随播放进度

功能

该有的都有。

发现

每日推荐、精选歌单、排行榜，以及单曲、歌手、专辑、歌单搜索。

我的音乐

喜欢的音乐、创建与收藏的歌单、最近播放、下载。

灰色歌曲解锁

无版权或已下架的歌曲，多源并行匹配，从其他已启用的音源中找到可播版本。

高音质

多档音质可选，播不了自动往下降，只报实测档位，不谎报。

离线下载

专辑、歌单、单曲都能下载，没网也能听。

注重隐私

登录凭证只保存在应用自己的钥匙串中。

还有：均衡器、睡眠定时、应用内在线更新。没有启动动画，打开就是主界面。
